# Smart Board - Teacher's Digital Whiteboard

A digital smartboard application for teachers built using tldraw SDK. This application allows teachers to create interactive whiteboard sessions, draw, write, and share content with students.

## Features

- Interactive whiteboard with drawing tools
- Save pages as SVG format
- AI-powered content generation (images and text)
- YouTube video search and embedding
- PDF and voice attachment support
- MongoDB storage for all board data

## Tech Stack

- Frontend: React.js with tldraw SDK
- Backend: Node.js with Express.js
- Database: MongoDB
- AI Text: Google Gemini API (free tier available)
- AI Image: Pollinations.ai (100% free, no API key needed)
- Deployment: Vercel (frontend) + Render (backend)
